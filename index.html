Integrasi Google Apps Script (GAS)

Panduan lengkap menghubungkan aplikasi ini ke Google Spreadsheet Anda secara gratis!

Kosongkan jika ingin menggunakan Mode Lokal/Demo Browser.

Langkah-Langkah Menyiapkan Database Google Spreadsheet

1

Buat Google Spreadsheet Baru

Buka sheets.new. Buat 7 Sheet dengan nama berikut persis (case sensitive):

    Sheet: Presensi, Nilai, Jurnal, Guru, Murid, Kelas, Mata Pelajaran
2

Buka Script Editor

Di Spreadsheet Anda, klik menu Ekstensi (Extensions) → Apps Script. Hapus semua isi file Code.gs.

3

Salin Source Code Backend GAS

Klik tombol di bawah ini untuk menyalin seluruh kode Google Apps Script, lalu tempel di editor Code.gs.

4

Deploy sebagai Web App

Klik tombol Deploy (Terapkan) → New Deployment (Penerapan Baru).
- Pilih Jenis: Web App (Aplikasi Web)
- Execute as (Jalankan sebagai): Me (Saya)
- Who has access (Siapa yang memiliki akses): Anyone (Siapa Saja)
Klik Deploy, berikan izin akses Google, lalu tempelkan URL Web App yang dihasilkan ke input di atas.
